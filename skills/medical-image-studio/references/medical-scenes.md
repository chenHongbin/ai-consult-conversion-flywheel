## 1. 患者问题科普卡

适合回答“为什么”“怎么办”“什么时候需要就医”一类大众问题。结构为：一个短标题、一个中心视觉、三个以内行动要点、底部提醒。

```text
为[平台]制作一张[比例]患者教育科普卡，面向[人群]。
核心只解释：[一个结论]。
标题必须原样显示：“[14字以内标题]”。
画面中心使用[温和的医学插画/简洁3D示意]表现[对象]；下方只保留三条短提示：[要点1]、[要点2]、[要点3]。
整体使用可信、克制、清晰的医疗视觉，配色为[品牌色/蓝绿白]，大字号，高对比，留白充足。
这是AI科普示意图，不表现真实患者，不生成诊断结果、处方、检查单、疗效承诺、医院排名或未提供的数据。避免血腥、恐吓、文字乱码和无关英文。
```

## 2. 疾病机制示意图

适合解释身体结构、疾病进程或治疗原理。必须先有医生/可靠资料提供的事实关系。结构为：正常状态 → 变化过程 → 可能影响，箭头清楚，标签少。

```text
制作一张面向普通人的医学机制示意图，主题是[主题]，用于[平台/课程]。
只根据以下已核验关系绘制：[用户提供的事实关系]。
采用三段式横向/纵向流程：[阶段A] → [阶段B] → [阶段C]；每段一个主视觉和一个6字以内标签，箭头方向明确。
使用非血腥、教育性的3D医学插画或信息图，不表现手术现场。标题必须原样显示：“[标题]”。
不要自行增加器官、病因、比例、数据、药名、治疗结论或疗效数字。底部留出“AI示意图，请以专业医生意见为准”的位置。
```

## 3. 医生 IP 封面

适合抖音/视频号/小红书医生内容封面。若使用真人照片，只能用用户提供且有权使用的照片；没有照片时使用不指向真实个人的剪影、手部、诊室物件或插画。

```text
制作一张[平台][比例]医生科普内容封面，主题是[主题]，目标读者是[人群]。
标题必须原样显示：“[标题]”，视觉焦点先看到标题，再看到[医生照片/可信医学物件/主题图示]。
风格专业、亲切、克制，像高质量医学杂志封面，不像促销广告。使用[品牌色]，人物区与标题区清楚分离，为平台头像和按钮预留安全区。
不得虚构医生身份、医院背书、患者证言、排名、权威认证或治愈承诺。没有授权真人照片时不要生成可被误认为真实医生的肖像。
```

## 4. 短视频三帧故事板

适合先规划短视频关键画面，不直接充当医学证据。三帧保持同一人物设定、色彩和空间关系。

```text
制作一张9:16画布内的三帧竖版医疗科普故事板，主题是[主题]。
第1帧：患者常见困惑/生活情境；第2帧：医生解释的核心机制；第3帧：安全、可执行的下一步提醒。
三帧使用统一角色、服装、诊室环境和配色；每帧只放一个6字以内小标题：[标题1]、[标题2]、[标题3]。
整体是教育性分镜插画，不冒充真实诊疗录像，不展示可识别患者信息，不生成具体诊断、处方、疗效前后对比或夸张痛苦。
```

## 5. 咨询解释卡

适合咨询师在不诊断的前提下解释流程、准备事项和下一步。不要用来诱导或替代医生。

```text
制作一张[比例]咨询解释卡，帮助[人群]理解[流程/准备事项]。
标题：“[标题]”。采用“现在知道什么—还需要确认什么—下一步做什么”三栏结构。
每栏最多两条短句，只使用用户提供的信息；用简洁图标和清楚箭头，不使用恐惧画面。
不得下诊断、承诺治疗效果、伪造检查结果或制造紧迫恐慌。底部保留“具体情况请由专业医生评估”的提醒区。
```

## 6. 医疗品牌活动图

适合义诊、直播、科普月或公开课海报。时间、地点、医生、机构和报名方式必须来自用户材料。

```text
制作一张[平台][比例]医疗科普活动海报，活动主题是[主题]。
信息层级：活动主题 > 时间地点 > 分享嘉宾/机构 > 报名方式。所有文字必须严格使用：[已核验文案]。
使用[品牌色]和[视觉风格]，整体专业、温暖、易读，为二维码预留空白框但不要生成假二维码。
不虚构专家头衔、机构背书、名额稀缺、治疗效果、患者案例或权威认证；没有授权照片时使用抽象医学图形或活动空间插画。
```

## 7. 一题多平台

同一个患者问题先锁定一个核心结论，再做变体：

| 版本 | 画面任务 |
| --- | --- |
| 抖音 9:16 | 强标题 + 单一视觉冲突，2秒内看懂 |
| 小红书 3:4 | 标题 + 三点科普，适合收藏 |
| 公众号 16:9 | 品牌化主视觉 + 留白，不堆正文 |
| 朋友圈 1:1 | 一句话结论 + 一个行动提醒 |
| 咨询解释卡 3:4 | 三步流程，便于面对面解释 |
| PPT 16:9 | 机制关系或前后逻辑，适合讲解 |

六个版本必须共享同一个事实底稿、核心结论、品牌色和禁用项。不要为了“变化”改变医学含义。
