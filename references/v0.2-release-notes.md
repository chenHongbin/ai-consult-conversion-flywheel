# v0.2 发布说明

## 这一版解决什么

v0.2 把“初始化一次、日常使用、持续蒸馏迭代”落成一个可运行的 Skill 工作流：学员仍然只安装一个 Skill，IMA、本地文件夹、长图 OCR、YouNavi 转写、批量蒸馏和能力包迭代都藏在 Skill 后面。

## 新增能力

- 本地资料入口：可用本地文件夹、IMA 知识库，或两者并用。
- 长微信截图处理：自动按重叠窗口切片，保留原图不变，再用本机 Tesseract 的 `chi_sim+eng` 做 OCR。
- 批量录音转写：默认调用已安装的 YouNavi `agent-cli`，逐条生成转写文本和清单；单条失败不阻断整批任务。
- 批量蒸馏准备：对 OCR/转写文本做去重、来源哈希、有限度脱敏、结果标签候选和人工复核队列。
- Dream Cycle：新增资料只处理新增或变化项，经标准化、候选提炼、评估后形成候选能力包，再由用户主动发布。
- 可追溯输出：每条候选都保留来源路径、来源哈希、媒体类型、结果标签和复核状态，避免经验规则脱离原始证据。

## 典型使用方式

```text
把新录音/微信长截图放入资料入口
        ↓
自动切片、OCR、YouNavi 转写、去重与脱敏
        ↓
生成案例清单、正向/反例、候选话术与问题队列
        ↓
固定测试集回归
        ↓
用户说“发布这一轮”后更新能力包
```

推荐每周固定执行一次批量处理。Skill 提供可重复执行的命令和目录约定；具体的每周定时触发由 WorkBuddy 或操作系统调度器负责，不在 Skill 内部静默创建定时任务。

## 当前脚本

- `scripts/init_dream_cycle.py`：v0.2 兼容脚本；v0.3 新用户使用 `scripts/init_consult_workspace.py`。
- `scripts/slice_long_images.py`：长图切片。
- `scripts/ocr_long_images.py`：长图切片并 OCR。
- `scripts/batch_transcribe_younavi.py`：批量调用 YouNavi 转写。
- `scripts/prepare_distillation_batch.py`：生成去重、脱敏、来源可追溯的蒸馏候选清单。

## 验证结果

- Skill 官方校验：通过。
- Python 脚本编译检查：通过。
- 本机 Tesseract `chi_sim`：可用。
- 一张受控外部长微信截图：已验证自动切片、重叠窗口和 OCR 清单生成；原始测试资料不随 Skill 发布。
- 一条受控外部录音：已验证 YouNavi 单条转写和批量清单生成；原始测试资料不随 Skill 发布。
- 初始化工作区：已验证 8 个阶段目录和来源配置生成。

## 已知边界

- OCR 和自动转写结果属于标准化证据，进入机构知识或能力包前仍须人工复核。
- 批量蒸馏默认生成候选包，不覆盖当前生效版本；只有用户明确要求发布时才更新。
- IMA 下载会受接口权限和频率限制影响；限流时保留失败记录，下次从用户重新指定的资料源继续，不反复重试，也不回退到任何历史示例资料。
- v0.2 不包含任何真实机构的知识库名称、原始资料、影子案例或外部试跑报告。
- Skill 不自动实时监听、自动发微信、自动绩效定级、自动临床建议，也不替用户创建系统级定时器。
