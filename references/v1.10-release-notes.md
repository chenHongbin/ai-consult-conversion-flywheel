# v1.10 发布说明：视觉与内容素材编译器

## 这次解决什么问题

v1.9 已经能在咨询分析后生成视觉 Brief，但视觉类型、患者决策阶段、顾虑和素材反馈之间还没有机器可读的连接。Excel《咨询图片19维度核对清单-20260811》提供了真实的客户素材需求地图，因此 v1.10 将其转化为可调用的素材目录和决策矩阵。

## 新增能力

- `references/visual-asset-catalog.json`：20 类视觉素材及其用途、阶段、顾虑、渠道、生产模式和 CTA。
- `references/visual-decision-matrix.json`：自然语言阶段/顾虑/目标别名、默认素材组合。
- `scripts/select_visual_asset.py`：根据咨询上下文选择主素材、备选素材和连续触达组合，并生成配文与视觉 Brief。
- `scripts/record_visual_feedback.py`：将素材使用、回复、预约和到院结果写入工作区反馈日志。
- 视觉路由输出契约扩展为素材类型、决策任务、素材组合、CTA 和反馈字段。

## 使用示例

```bash
python3 scripts/select_visual_asset.py \
  "患者担心医院不正规，帮我做一组聊天跟进素材" \
  --channel chat

python3 scripts/select_visual_asset.py \
  "患者说太贵，准备做费用抗拒点QA图" \
  --asset-type objection_qa --channel chat

python3 scripts/record_visual_feedback.py <工作区根目录> \
  --asset-id objection_qa --channel chat --status sent \
  --replied yes --appointed unknown
```

## 设计原则

视觉模块的核心交付不是单张图片，而是：

```text
素材
+ 决策任务
+ 配套文案
+ 推荐 CTA
+ 组合顺序
+ 使用反馈
```

所有 Excel 中列出的素材类型都进入生产目录；图片生成仍由嵌入式 `medical-image-studio` 执行。v1.10 不自动发送或发布素材，客户可以直接要求改图、改文案、换比例和重新组合。
