# v0.8：双入口初始化与咨询销冠蒸馏提示词

## 新增内容

- 当前工作空间已有资料时，先只读扫描，再选择“接管当前空间”或“新建独立资料区”；
- 明确支持 `scripts/init_consult_workspace.py --use-root` 接管当前空间；
- 没有机构知识库但有大量录音时，可以先生成“临时咨询能力包”；
- 增加从资料盘点、转写/OCR、标签、案例对照、行为卡、知识绑定、固定测试到候选发布的完整提示词；
- 明确区分机构知识和咨询案例，防止从录音猜测价格、医生、地址、疗效或机构流程；
- 增加有知识库/无知识库的数量建议、产物边界和下一步动作。

## 两条入口

```text
已有机构资料
  → 只读盘点
  → 接管当前空间 / 新建独立资料区
  → 机构初始化
  → 单条案例验证
  → 批量蒸馏

只有录音或聊天
  → 资料质量盘点
  → 转写/OCR与脱敏
  → 优秀/普通/失败对照
  → 临时咨询能力包
  → 补齐机构知识
  → 机构专属能力包候选版
```

## 关键边界

没有机构知识库时，Skill 只提炼咨询行为模式，不把录音中的机构事实当作已确认事实。所有未知价格、医生、地址、疗效、治疗周期、服务流程和医疗建议都必须标记为“待机构确认”。任何能力包先影子运行，再由管理者审核和发布。
