# 基础咨询运行时

## 作用

基础运行时是 AI咨询转化飞轮安装后立即可用的最小能力层。它不依赖机构蒸馏，不依赖 IMA，也不要求用户先建立完整知识库。

它解决的是咨询转化中不随机构事实变化的判断问题：

- 患者现在处于哪个阶段；
- 患者真正的顾虑是什么；
- 咨询师在哪个动作上失去推进机会；
- 下一步应该如何继续沟通；
- 如何进行单动作陪练和复盘。

## 三层运行时

每次回答都按以下顺序合并：

```text
基础咨询运行时（始终存在）
    + 团队已发布能力与已确认机构知识（如果存在）
    + 当前用户的个人成长层（如果存在）
```

优先级为：

```text
医疗安全与隐私
> 已确认机构事实
> 团队正式规则
> 个人已验证经验
> 个人候选经验
> 通用基础方法
```

## 无蒸馏模式

无蒸馏时，运行状态必须明确标记为 `base_only`，但不能停止工作。可以直接分析电话、微信、私信、录音转写和截图 OCR，也可以做费用、效果、信任、到院推进、爽约回访和新人陪练。

输出中允许给出通用方法和安全表达，但必须明确：

- 机构价格、医生、地址、项目、疗效、周期和优惠尚未确认；
- 当前建议不是该机构的专属 SOP；
- 如果需要机构专属回答，再启动初始化或蒸馏。

## 路由原则

用户不需要知道专项模块名称。总入口根据任务路由到一个主专项，必要时再挂载一个辅助专项。一次回答只设置一个主目标，例如“先判断费用顾虑”，不要同时输出完整销售培训报告。

每次内部路由应记录：`route_id`、`runtime_mode`、`matched_terms`、`references` 和 `permission`。路由不应把原始患者资料写入 Skill 包，也不应绕过机构事实和医疗安全边界。

## 默认输出

```text
现在在哪一步 → 患者最在意什么 → 你下一步做什么 → 可直接使用的安全表达 → 哪些话不能说
```
