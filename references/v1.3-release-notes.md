# v1.3：全量样本纳入、结果加权与八步法统一分析

## 修复的问题

- 不再把“已到院/未到院”当成是否分析的硬门槛；未知结果样本也进入批量处理；
- 不再把内训、会议和策略录音误当成患者成功案例；它们单独作为方法参考；
- 不再让文件夹名称直接代表真实结果；路径标签必须标记为待确认；
- 单条分析、批量蒸馏、陪练和团队复盘统一使用咨询转化八步法；
- 前台输出改用通用方法名称，不暴露内部培训来源人员姓名。

## 新增规则

每条可读材料记录：`source_nature`、`sample_role`、`analysis_route`、`sample_weight`、`result_weight` 和 `outcome_provenance`。

- 正向参考：已到、预约、成交、优秀、红板等信号；
- 反向参考：未到、爽约、流失、失败、黑板等信号；
- 普通/对照：用于比较，不自动判为好或坏；
- 未知案例：结果待确认，但仍然分析；
- 方法参考：内训、会议、策略和模板，提炼方法，不证明患者结果。

结果标签只影响证据汇总权重，不能代替逐轮证据，也不能让单个案例直接晋升为机构规则。
