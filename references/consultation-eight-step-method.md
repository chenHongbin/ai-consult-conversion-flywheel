# 咨询转化八步法（默认分析引擎）

这是本 Skill 对录音、电话、微信、私信、截图 OCR 和陪练统一使用的咨询分析框架。它是通用方法底座，不等于任何机构的医生、价格、疗效或流程事实。

## 八步主干

| 步骤 | 目标 | 主要检查 |
|---|---|---|
| 1. 破冰信任 | 让客户愿意继续聊 | 身份是否清楚、是否先回应再提问、是否给出继续沟通的理由 |
| 2. 需求探询 | 听清客户要解决什么 | 现状、困难、影响、期望是否逐步问清；不能只采集表面信息 |
| 3. 痛点共鸣 | 让客户感到被理解 | 是否复述关键经历、承接情绪、确认真正困扰；不夸大风险 |
| 4. 价值塑造 | 说明为什么值得继续了解 | 只使用已审核的机构事实、服务边界和证据；不把案例当疗效保证 |
| 5. 攻破抗拒 | 处理费用、效果、信任、距离、时间和家人意见 | 先听完，再共情、追问真实顾虑、针对性回应，最后回到下一步 |
| 6. 稀缺营造 | 说明为什么现在可以行动 | 只能使用真实可核验的医生档期、活动、时间或流程，不制造虚假稀缺 |
| 7. 封闭邀约 | 把意向变成具体动作 | 给出清楚、低压力、可选择的下一步，确认时间/联系方式/负责人 |
| 8. 确认防鸽 | 降低爽约和失联 | 说明到院前准备、提醒节点、变更方式和回访理由；未到院也要复盘原因 |

阶段可以跳转或循环：高意向客户可能从 1→2→4→7；费用、效果或信任顾虑出现时，回到第 5 步；第 8 步不只适用于已预约客户，也适用于失联、爽约和长期培育。

## 三层分析

每条对话都按三层输出：

1. **阶段层**：当前在第几步，已经完成什么，下一步缺什么；
2. **动作层**：咨询师观察到什么信号，做了什么判断，采用了什么动作，客户如何回应；
3. **节奏与边界层**：信息、文字/语音/图片、回应、行动指令是否形成节奏，是否出现虚构事实、过度承诺或临床越权。

## 贯穿工具

- **SPIN**：现状、困难、影响、期望，用于第 2 步；
- **LEARN**：倾听、共情、追问、回应、下一步，用于第 5 步；
- **FABE**：特征、优势、利益、证据，用于第 4 步，但证据必须来自已审核机构资料；
- **45 节奏检查**：在适合的渠道检查优势材料、语音、图文分隔和行动指令是否形成节奏；不把“缺少图片/语音”机械判为错误；
- **预期管理、倾听—提问—回应、共识目标**：三项底层检查，贯穿全部步骤。

## 统一输出字段

单条分析至少输出：

```text
样本性质：患者咨询 / 团队内训或策略 / 方法模板 / 未知
结果状态：已确认 / 路径标签待确认 / 未知
当前阶段：第几步及证据
患者显性问题与可能真实顾虑
咨询师做对的动作
流失或推进断点
下一步建议与可直接使用的安全表达
需要机构确认的事实与不能说的内容
```

结果状态只影响结论权重，不替代逐轮证据。已到/预约/成交可以作为正向结果证据；未预约/爽约/流失可以作为反向结果证据；没有结果或只有文件夹标签的样本进入“待确认”，仍然必须分析。

## 对内训、会议和策略录音的处理

这类资料可以提炼“判断原则、培训要求、话术结构和管理动作”，但不能被写成“患者真实反应”或“到院成功证据”。输出中标记为“方法参考”，并与患者咨询案例分开。

## 安全边界

不做诊断、处方或临床建议；不承诺治愈、疗效、周期或成功率；不补写未确认的医生、价格、地址、活动和资质；涉及医疗判断时转执业人员或管理者确认。
