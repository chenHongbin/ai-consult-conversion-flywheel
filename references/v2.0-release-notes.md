# v2.0 发布说明：咨询团队管理与能力复制系统

v2.0 把 AI咨询转化飞轮从“对话分析 Skill”升级为“咨询主管每日经营工作台”。核心用户是咨询主管、咨询总监和机构负责人，一线咨询师作为执行端继续使用分析、回复、回访、陪练和视觉素材能力。

## 核心闭环

```text
发现团队断点 → 找到优秀对照 → 提炼销冠动作 → 生成训练任务
→ 一线执行 → 复查新样本 → 观察行为和结果 → 沉淀团队能力
```

## 本版新增

- 一通录音、一段微信或一张截图即可形成三层管理卡；
- 追加式沟通样本、管理事件、训练动作和能力晋升记录；
- 主管“开始今天的工作”等七个自然语言入口；
- 每名员工一个当前主要训练动作；
- 今日主要团队断点和 P0/P1/P2 管理待办；
- 个性化服务链、安心感形成链和团队复制链；
- 五级女娲能力晋升与严格门槛；
- 断网可用、只读、自包含的本地咨询管理工作台；
- 咨询转化率、预约到院率、有效咨询到院率、到院成交率及管理/训练指标；
- 夜间扫描完成后自动重建工作台，白天支持手动刷新；
- 一键创建带完整管理闭环的合成演示工作区。

## 三个公开命令

```bash
python3 scripts/generate_management_dashboard.py <工作区> --period today --date YYYY-MM-DD
python3 scripts/record_management_action.py <工作区> --task-id <任务ID> --event complete --note <说明>
python3 scripts/create_demo_management_workspace.py <目标目录>
```

## 数据解释边界

没有预约、到院或成交结果时，系统只说明行为改善、动作采用和主管节省时间，不宣称转化提升。所有百分比携带周期、分子、分母、来源和完整性状态；缺失值不会被替换为零。

## 包边界

公开基础 Skill 包含主管工作台能力。机构一线团队包继续使用显式白名单，不包含主管工作台脚本、团队蒸馏、统一发布和全团队数据脚本。两种包均不携带真实工作区、患者资料或生成的本地 HTML。
