# v1.5 发布说明：患者决策洞察与画像驱动陪练

## 新增

- 新增患者决策洞察层：决策状态、疑义意图和合成陪练场景。
- 新增 `scripts/commit_patient_insight_candidate.py`，对候选执行证据、反例、脱敏、禁用画像标签和审核门槛校验。
- 工作区初始化新增 `患者洞察` 后台目录和 `07_我的产出/05_患者决策洞察与陪练`。
- `load_active_capability.py` 同时加载咨询能力、机构知识和患者洞察运行时。
- 团队 Skill 发布包同步已审核的患者决策洞察，但不包含患者级画像、原始录音或聊天内容。
- 批量标准化清单增加精确文本去重簇、独立案例标记、授权状态、隐私风险和三类置信度字段。

## 运行边界

- 患者画像只作为群体级决策状态假设；当前对话中必须先验证，不能当成患者事实。
- 不推断收入、职业、性格、心理、支付能力、疾病严重程度或成交潜力。
- AI 陪练只使用脱敏聚合信息生成合成患者，不使用真实患者隐性画像。
- 小样本只能输出“本批观察到”，不能泛化为“患者通常”。
- v1.5 不自动发送微信、不做实时监听、不做自动绩效、不提供诊断或治疗建议。

## 使用顺序

1. 首次运行完成全量扫描、转写/OCR和批次标准化。
2. Agent 同时输出 `candidate.json`、`knowledge-candidate.json` 和 `patient-insight-candidate.json`。
3. 分别审核三类候选；患者洞察额外要求隐私审核和反例。
4. 通过固定测试后再发布，团队包以一个 `.skill` 文件同步。
