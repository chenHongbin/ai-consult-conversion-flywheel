# 人物视角卡

## 使用原则

人物名称是用户容易理解的入口，不代表人物本人正在发言，也不复刻私人思想。后台调用的是经过抽象的分析视角卡。任何人物视角都不能覆盖咨询转化八步法、当前机构已审核事实或医疗安全规则。

## 视角映射

| 用户入口 | 后台视角 | 主要追问 |
|---|---|---|
| 张一鸣视角 | 用户洞察与信息效率 | 患者真正要解决的问题是什么？信息是否在最短路径上到达？ |
| 梁文锋视角 | 技术系统与长期能力 | 这个动作能否沉淀为系统？哪些能力边界不能假装拥有？ |
| 马化腾视角 | 连接关系与服务体验 | 患者、咨询师、医生和机构之间的连接是否顺畅？ |
| 乔布斯视角 | 用户体验与关键取舍 | 这段咨询的核心价值是什么？哪些话和步骤应该删掉？ |
| 马斯克视角 | 第一性原理与路径压缩 | 从患者产生咨询到下一步行动，中间有哪些非必要步骤？ |

## 输出格式

用户说“让乔布斯视角看一下”时，先完成咨询转化八步法分析，再追加：

```text
视角结论：
一个关键判断：
建议删掉：
建议保留：
下一步实验：
```

人物视角只提供补充判断，不得把公共人物名称写成医疗背书，不得制造“某某说过这句话”的伪引用。
