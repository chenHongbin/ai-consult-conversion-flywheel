# 工作区初始化契约

## 标准位置

用户选择的文件夹叫“资料来源根目录”，Skill 创建的标准工作区必须是它下面的：

```text
用户选择的工作空间/
├── 原有资料……
└── 咨询转化工作区/
    ├── 01_机构介绍/
    ├── 02_科室项目与服务/
    ├── 03_咨询流程与标准/
    ├── 04_优秀咨询案例/
    ├── 05_普通失败与未预约案例/
    ├── 06_团队培训与反馈/
    ├── 07_我的产出/
    ├── 08_团队管理/
    ├── _系统/
    ├── README_先看这里.md
    └── _系统/工作区清单.json
```

截图中看到的 `01_机构介绍` 到 `08_团队管理` 和 `_系统`，如果它们位于 `咨询转化工作区/` 内，就是正确结构；文件管理器当前打开的文件夹可能只是省略了上一级名称。

## 初始化执行规则

这是一个低自由度动作，Agent 不得根据自己的理解另起文件夹名称，也不得用“资料库”“知识库”“客户资料”“AI工作台”等替代名称。

必须依次执行：

```bash
python3 scripts/init_consult_workspace.py <用户选择的工作空间根目录> --name 咨询转化工作区
python3 scripts/verify_consult_workspace.py <用户选择的工作空间根目录>
```

只有校验结果为 `canonical`，才可以向用户说“初始化完成”。如果用户明确说“当前选中的文件夹本身就是咨询转化工作区”，才允许使用 `--use-root`；否则不允许使用这个参数。

## 原有资料处理

初始化不会移动、改名、删除用户原有资料。首次蒸馏仍然扫描用户明确授权的整个资料来源根目录；标准工作区只负责承载处理结果、候选能力和发布版本。

未知的原有文件夹不是初始化失败，也不能被自动改名。Agent 应报告它们属于“待识别原有资料”，并继续使用标准工作区目录。
