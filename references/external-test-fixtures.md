# 外部测试夹具与隐私隔离

本 Skill 是可复制的通用产品，默认不携带任何机构知识、患者资料、真实录音、微信聊天、医院资料或外部测试报告。

## 资料角色

- **Skill 内置内容**：通用咨询方法、数据结构、处理脚本、安全规则和合成回归案例。
- **用户机构资料**：当前用户主动提供并授权使用的机构事实、团队案例和业务资料，只属于当前工作区。
- **外部测试夹具**：为了验证 IMA/本地接入、OCR、YouNavi 和蒸馏链路而临时使用的资料，不属于 Skill，也不属于默认知识。

## 接入闸门

外部测试只能按以下顺序进行：

`明确指定 → 明确用途 → 权限/授权检查 → 原始区隔离 → 脱敏 → 处理 → 结果审查 → 删除或受控归档`

任何一个环节缺失，都只能输出“暂不使用/待授权”，不能把资料继续送入蒸馏。

## 禁止进入发布包的内容

- 知识库名称、机构名称、医院名称、医生姓名和团队成员姓名；
- 媒体 ID、下载地址、API 凭证和访问令牌；
- 录音、图片、HTML、转写、OCR、患者案例和聊天原文；
- 从特定机构资料直接提炼出的病种数量、团队表现、话术句子或影子案例；
- 能让下一位用户推断出原始机构或患者身份的组合信息。

## 允许进入通用 Skill 的内容

只有完全去机构化、去身份化、不可回溯到原始资料，并经过人工复核的抽象设计，例如：

- “长图先切片，再 OCR，再保留位置证据”；
- “已到院不等于咨询质量优秀”；
- “批量蒸馏必须同时包含正向、普通、失败和待确认样本”；
- “无法确认授权时暂停处理”。

这些是通用处理原则，不是任何具体机构的事实或销冠规则。
