# 一线团队运行模式

团队发布包是一线咨询师的运行版，不是主管蒸馏版。用户仍然只安装一个“AI咨询转化飞轮” Skill，但运行权限分为两层：

- **一线可用**：扫描自己的录音、微信和截图；调用 YouNavi 转录；长图切片与 OCR；去重和标准化；分析自己的咨询；学习已发布的团队案例；AI 陪练；记录个人成长。
- **主管专用**：全团队蒸馏、候选规则审核、统一发布、回滚、团队报告和员工私密资料访问。

## 个人成长层

个人资料只写入当前工作区的 `_系统/个人成长/`，不写入 Skill 安装包，也不会自动修改团队运行版。个人能力可以影响自己的分析、陪练和提醒，但不能覆盖医疗安全、已确认机构事实或团队正式规则。

运行时优先级固定为：

```text
医疗安全与合规
> 已确认机构事实
> 团队正式规则
> 个人已验证能力
> 个人候选经验
> 通用基础方法
```

一线分析他人的优秀案例时，默认只作为个人学习材料。只有用户明确说“推荐给主管蒸馏”，才生成推荐记录；推荐记录不等于团队规则，必须由主管在下一轮 Dream Cycle 中审核。

## 团队更新

安装新的团队版本时，只更新团队运行层：

```text
Team-v1.8 → Team-v1.9
```

个人案例、训练记录和个人能力候选保存在工作区外部状态中，不随 Skill 包覆盖。若个人能力候选依赖旧团队版本，更新后标记为“待重新验证”；与团队新规则冲突时，当前回答优先使用团队新规则，但个人历史不会删除。

## 资料处理

一线可以对个人资料执行转录、OCR、去重和批量分析，但不得使用团队蒸馏、候选写回、发布和回滚入口。IMA 资料先建立清单再按优先级读取；遇到配额或权限错误立即记录并暂停该资料源，不重复撞接口。
