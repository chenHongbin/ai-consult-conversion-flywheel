# V2.1 逐案报告合同

## 使用时机

分析一通录音、一组微信长截图、一段聊天文本，或提交 `daily_review.py claim` 返回的任务时读取本合同。

## 第一性原理

报告的价值不在于描述得长，而在于让用户知道：患者卡在哪里、咨询师哪一个动作影响了推进、下一次只改什么。关键判断如果不能回到原始证据，就不能作为员工辅导或团队学习依据。

## 必填结构

Agent 提交的 JSON 必须包含：

```json
{
  "summary": ["患者状态", "主要顾虑", "最关键下一步"],
  "material_quality": "complete|partial|poor",
  "stage": "八步法当前阶段",
  "patient_concern": "患者主要顾虑",
  "breakpoint": "本案最主要的一个断点",
  "patient_facts": ["患者明确表达的事实"],
  "consultant_actions": ["咨询师实际采取的动作"],
  "strengths": ["做得好的动作及条件"],
  "verified_strength": "本案最明显的一个长板",
  "missed_opportunities": ["错失机会及影响"],
  "champion_comparison": ["最佳实践下的判断和动作"],
  "next_service_action": "当前最适合患者的下一步",
  "safe_response_draft": "可参考但不越过医疗边界的表达",
  "training_action": {
    "key_action": "下一次只训练一个动作",
    "pass_criteria": "可以从新案例观察的通过标准",
    "review_scenario": "什么新案例出现时复查"
  },
  "training_followup": {
    "target_action_observed": true,
    "evidence_locator": "截图第4段/录音03:20",
    "note": "仅当领取任务中带有 current_training 时必填"
  },
  "evidence": [
    {"locator": "截图第3段/录音02:15/文本第8行", "quote": "必要的短原句", "claim": "支持什么判断"}
  ],
  "risk_level": "P0|P1|P2",
  "case_signals": ["rejected|lost|no_reply|complaint|high_intent_stalled|key_stage_stalled|representative_positive|representative_negative"],
  "novel_issue": false,
  "unknowns": ["材料中无法确认的信息"],
  "deep_analysis": false
}
```

`summary` 可以是三项列表或短文本。`evidence` 至少一项，每项必须有 `locator`。无法读取材料时不得伪造证据，应把任务标记失败或隔离。

若领取的任务包含 `current_training`，报告必须增加 `training_followup`，只判断该训练动作在本案中是否出现并给出证据位置。不要因为本案暴露了新问题就同时启动第二个训练动作。

若任务是患者组合报告，`evidence` 必须覆盖所引用的各渠道材料，并在结论中说明患者阶段、顾虑和咨询动作随时间的变化；不能把多段对话简单拼接成一个无时间顺序的故事。

## 标准报告升级原则

保留阶段、患者原话、真实顾虑、好动作、坏动作、销冠动作和下一步；新增：

- 证据位置；
- 材料完整度；
- 事实、推断和未知的区分；
- 医疗安全边界；
- 唯一训练动作和可观察通过标准。

## 全量标准与重点深析

每个有效案例都生成上述标准报告。以下情况把 `deep_analysis` 设为 `true` 并展开因果链、替代动作和复查条件：

- P0 医疗、隐私、承诺或合规风险；
- 患者明确拒绝、投诉、失联或高意向后停滞；
- 关键推进阶段没有明确下一步；
- 团队未见过的新问题；
- 代表性强的优秀或失败案例；
- 主管指定。

命中上述语义信号时必须把 `deep_analysis` 设为 `true` 并完成深析；主管可以通过任务优先级覆盖增加或移除非 P0 深析。P0 永远不能取消。

## 禁止项

- 不把推断写成患者事实；
- 不从对话推断收入、性格、疾病严重程度或成交潜力；
- 不在结构化报告、证据短引或训练卡中保留手机号、证件号、邮箱、微信号等直接标识；提交前必须脱敏；
- 不用机构未确认的医生、价格、地址、疗效和案例；
- 不把一份成功报告直接晋升为团队最佳实践；
- V2.1 的 `outcome` 固定为 `unknown`，不宣称提升转化率。
