# 分析、辅导与输出规范

所有录音、电话、微信、私信、截图 OCR 和陪练默认按 [consultation-eight-step-method.md](consultation-eight-step-method.md) 分析。先判断资料性质和结果证据，再做八步法逐轮标注；“已到/未到”只是结果权重，不是纳入条件。

## 咨询阶段

每次运行前先读取当前工作空间的机构能力包：

```text
python3 scripts/load_active_capability.py <工作空间根目录> --format markdown
```

同时读取已发布的患者决策洞察运行时。优先使用当前机构已发布能力包中的机构事实、销冠阶段动作、顾虑规则、反例和训练要求；患者洞察只提供群体级状态假设，必须通过当前对话中的一个问题验证，不能把“这类患者”当成当前患者事实。没有 active 能力包时，使用基础 Skill，并明确标记“机构专属经验尚未建立”。能力包只改变分析上下文，不替代医生判断，也不把原始患者个案直接写入回答。

使用八步法阶段模型；允许跳步和循环，但必须说明证据：

1. 破冰信任；
2. 需求探询；
3. 痛点共鸣；
4. 价值塑造；
5. 攻破抗拒；
6. 稀缺营造；
7. 封闭邀约；
8. 确认防鸽、爽约处理或长期回访。

对每条批量资料额外标注：

- `source_nature`：患者咨询、团队内训/策略、方法模板或未知；
- `sample_role`：正向参考、反向参考、普通/对照、未知案例或方法参考；
- `sample_weight`：优秀/红板或失败/黑板等明确筛选信号高，普通/对照中，未知低，方法参考仅作上下文；
- `result_weight`：内容或机构数据已确认高，只有路径/文件名标签中，没有结果低，方法参考仅作上下文；
- `outcome_provenance`：结果来自对话、机构数据、文件夹/文件名标签或未提供。

内训和策略资料可以提炼判断原则、话术结构和管理动作，但不能写成患者反应、到院证据或疗效证据。

渠道只是上下文：广告、医生 IP、患者分享、矩阵号、搜索和转介绍可以影响信任基础与开场方式，但不能改变事实核验和患者自主选择原则。

## 单条分析卡

按以下结构输出：

### 结论

- 当前阶段：
- 患者想解决的问题：
- 当前主要顾虑：
- 最重要的下一步：

### 证据

引用必要的原文、消息位置或录音时间点。明确区分患者原话、机构事实和 AI 推断。

### 诊断

- 做对的动作；
- 发生断点的位置；
- 断点根因；
- 如果换一种做法，预期改善什么。

### 动作建议

给出 2～3 个表达版本，并说明各自适用条件。先写行动目的，再写表达，不要堆砌话术。

### 风险

标注事实缺口、隐私风险、临床越权、疗效承诺、虚构信息或不当施压。

### v2.0 管理者三层输出

管理者分析团队成员的一条录音、微信或截图时，在单条分析卡后追加：

1. `患者推进`：当前不确定性、下一步服务、可直接回复、内容/视觉处方；
2. `员工辅导`：一个已验证优势、一个能力断点、下一条只改的动作；
3. `团队学习`：是否重复出现、正反样本、是否进入女娲候选。

随后使用 `scripts/record_communication_sample.py` 记录结构化片段。拿不到完整患者资料不阻塞分析，也不假装已有完整患者旅程。

## 团队复盘卡

一线主管优先使用五个日常动作：晨间任务排队、单条录音诊断、咨询师即时问答、回访安排、下午单主题复盘。每个动作先给最简结果，再提供证据展开。

即时问答优先输出：

`直接回：……`  `不要说：……`  `涉及诊疗：转执业人员`

当当前对话适合继续触达时，附带“咨询素材包”：朋友圈短文案、微信下一步文案、推荐视觉类型和一条生图提示词；如果视觉能降低患者的理解成本，直接调用嵌入式医疗生图引擎生成主图。视觉路由和三个试跑提示词见 [consultation-visual-content-loop.md](consultation-visual-content-loop.md)。

回访安排优先输出：

`回访时间：……`  `回访理由：……`  `一条草稿：……`  `停止条件：……`

批量分析时优先输出：

1. 样本量和口径；
2. 各阶段断点；
3. 团队共性问题；
4. 可复制的优秀行为；
5. 三个培训优先级；
6. 一个下周行动；
7. 需要补齐的机构知识。

当管理者资料不足时只输出：“缺少什么、暂不能判断什么、请补充哪一个信息”。AI 判断被纠正后，先标记错误、改正阶段/顾虑/证据并重跑本案，不自动写入团队规则。

不要单凭转化率自动给个人定级。把数量、渠道、病种、阶段、样本质量和证据一起呈现。

## 教练与陪练

辅导采用“事实—影响—替代动作—练习—复盘”的顺序。对新人先教判断，再教表达；对销冠案例先拆行为条件，再拆语言风格。

陪练时让 AI 根据已审核的患者决策状态生成合成患者，只练一个动作；不得读取真实患者隐性画像，不得模拟临床诊断，不得诱导咨询师使用违规承诺。评分应关注：回应相关性、信息准确性、倾听、推进节奏、下一步清晰度和安全边界。
