# 资料源与增量处理

## 首次初始化的简单入口

首次使用只让用户选择一种或两种资料源：

- “先用空白工作区/合成测试，不接入外部资料”；
- “用 IMA 知识库”；
- “用电脑上的本地文件夹”；
- “两种都用”。

默认选择第一项。只有用户主动指定资料源并确认用途后，才自动创建或记录外部资料配置。不要要求用户理解 API、媒体 ID、游标或同步协议。

外部资料不是 Skill 内置内容。机构名称、知识库名称、媒体 ID、原始录音、聊天截图、转写和 OCR 结果都只保留在当前用户明确指定的受控工作区，不写入 Skill 源码、默认上下文、通用测试集或发布包。

## 本地资料源

Skill 首次使用时调用 `scripts/init_consult_workspace.py`，在用户选定的工作空间根目录下创建 `咨询转化工作区/`。用户把资料放入 `01_机构介绍` 到 `06_团队培训与反馈` 中最接近的文件夹即可；如果要做团队管理，把资料放入 `08_团队管理/01_成员/员工编号_姓名/01_今天放这里`，会议录音放入 `08_团队管理/02_团队会议/01_今天放这里`，数据表放入 `08_团队管理/03_团队数据/01_今天放这里`；不确定时可以先放 `01_机构介绍`，Skill 会自动分类。

Skill 按文件哈希判断新增、重复和变更：

- 新文件：进入本轮处理；
- 哈希重复：跳过但保留来源记录；
- 内容变化：作为新版本重新处理；
- 无法读取：移动或记录到 `_系统/失败记录/`。

原始文件不修改。切片、OCR 和转写输出写入对应处理目录。
原始区、处理中间区、候选区和已发布能力包分开保存；未脱敏资料不得跨入候选区或团队学习区。

## IMA 资料源

IMA 读取顺序：用户选择知识库 → 列出知识库目录 → 文件夹 → 媒体条目 → `get_media_info` → 下载或读取正文。文件夹不是文件，不能直接下载；笔记型媒体需要作者权限，权限错误必须标记而不是重试到耗尽额度。

主路径支持 WorkBuddy、Trae、Codex、Claude 和普通本地工作区。IMA 是第二路径：在 IMA 原生环境中使用宿主登录上下文；在普通环境中先检查已有凭证，没有凭证时不阻塞本地模式。任何情况下都不根据历史示例自动选择知识库。

同步时优先使用用户指定的文件夹；每轮保存已处理媒体指纹和时间，避免重复拉取。遇到“获取次数上限”“请求频率超限”时立即暂停本轮，记录失败原因，等待下一轮，不继续撞接口。
不得根据历史配置、示例名称或上一次测试自动寻找其他知识库；每次接入都必须绑定当前用户明确指定的资料源、用途和授权状态。

## 录音处理

默认调用本机 YouNavi：

```text
/Applications/YouNavi.app/Contents/Resources/backend/agent-cli -f json audio transcribe "<audio>"
```

使用 `scripts/batch_transcribe_younavi.py` 批量处理。保留说话人、时间点和转写质量；YouNavi 不可用时记录失败，不偷偷切换到其他本地模型。

## 长图处理

使用 `scripts/ocr_long_images.py`：

1. 识别图片尺寸；
2. 超过默认高度时按 2400px 一段、160px 重叠切片；
3. 使用 Tesseract `chi_sim+eng` OCR；
4. 保存切片、OCR 文本和 `ocr_manifest.jsonl`；
5. 后续案例标准化保留原图路径和切片位置，避免消息顺序丢失。

OCR 只是标准化证据，不等于事实确认。姓名、电话、微信和病历号自动模式脱敏后，仍标记人工复核。
