# v1.0：首次全量接管与增量蒸馏编排

## 本版解决的问题

修复“工作空间里有几十条录音，但只读取一条已有 TXT 就开始蒸馏”的核心缺陷。

## 行为规则

- 第一次说“蒸馏销冠”“蒸馏这一批”或“更新咨询能力”：递归扫描当前工作空间根目录的全部候选资料；
- 用户明确说“只分析这一条”：才进入单案例模式；
- 全量处理前生成资料索引和覆盖率报告；
- 已有转写直接配对，未转写录音进入 YouNavi 批量队列；
- 长图进入切片/OCR队列，微信 HTML 保留消息顺序；
- 覆盖率未完成时，只能输出部分样本候选分析；
- 全量处理完成后，后续根据文件哈希只处理新增或变化资料。

## 新增脚本

- `scripts/inventory_workspace.py`：全工作空间资料索引、哈希去重、已有转写匹配和覆盖率报告；
- `scripts/run_full_distillation.py`：统一编排扫描、YouNavi 批量转写、长图 OCR 和蒸馏闸门。

## 安全边界

原始资料只读、不移动、不删除。`_系统`、处理输出、缓存、Git 和临时文件不会作为咨询证据重复进入队列。IMA 示例知识库不写入 Skill，也不作为默认资料源。
