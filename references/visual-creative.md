# 视觉弹药能力

本文件负责前台使用原则；完整的“对话分析 → 文案 → 视觉 → 反馈”闭环，以及三类示例提示词，读取 [consultation-visual-content-loop.md](consultation-visual-content-loop.md)。实际生图由嵌入式 `skills/medical-image-studio/` 完成，学员仍只安装一个 AI咨询转化飞轮 Skill。

## 定位

视觉能力不是独立的海报设计工具，而是咨询转化中的视觉弹药：降低患者理解成本、陌生感和行动成本，帮助咨询师完成解释、触达、培训和复盘。

用户只需要说目标，例如：

- “帮我做一张到院准备图。”
- “把这个案例做成朋友圈海报。”
- “做一张普通回复和销冠回复的对比图。”
- “把医院环境照片优化成朋友圈配图。”
- “把这条录音做成培训图。”

直接生成，不在生成前让用户确认。生成后用户可以继续说“换一种风格”“文案短一点”“改成朋友圈比例”来迭代。

在咨询对话分析中，默认附带一份“咨询素材包”：朋友圈短文案、微信下一步文案、推荐视觉类型和可执行的生图提示词。当前对话确实需要视觉降低理解成本时，直接调用嵌入式生图引擎生成一张主图；内部复盘或不适合触达时只输出素材 Brief，避免无意义消耗。

执行时优先调用内置图像生成能力；有真实本地图片时先读取图片，再根据当前环境支持的图片编辑/参考图能力处理。若当前服务商只支持文生图，就明确按“重新生成示意图”处理，不声称使用了原图。图片只是预览或成品资产，不自动发送给患者或发布到渠道。用户无需事前逐次确认，但系统会自动把无法核验的真实患者、真实疗效、真实医院客流和真实医生身份降级为“AI示意图”，不将示意图包装成真实证据。

## 内部路由

| 用户目标 | 默认资产 | 主要事实来源 |
|---|---|---|
| 推进到院 | 到院流程图、地址/路线卡、就诊准备卡 | 已审核机构事实 |
| 解释顾虑 | 费用/流程/距离/服务说明卡 | 机构事实 + 已审核 FAQ |
| 持续触达 | 朋友圈海报、回访关怀图 | 机构事实 + 用户指定主题 |
| 医生内容 | 科普配图、知识卡、短视频封面 | 已审核科普资料 |
| 患者种草 | 匿名经历卡、过程示意图 | 已授权素材或脱敏案例 |
| 团队训练 | 话术对比图、动作拆解图、复盘图 | 已审核案例和能力包 |

## 事实和素材处理

1. 用户给出的明确文案优先按原意使用；
2. 机构名称、地址、价格、医生、活动、项目和服务只从已审核事实读取；
3. 缺少机构事实时直接用中性文案或占位信息，不编造具体事实；
4. 真实医院照片可以优化、裁切、调光和排版；没有真实照片时标记为“环境示意”；
5. 用户提供的真实案例图片只做脱敏、排版和信息整理，不凭空改变病情变化；
6. 没有真实疗效证据时，生成“过程示意”“咨询案例示意”或“科普图”，不伪装成真实治疗前后。

## 默认出图规则

- 不先问尺寸：根据用途自动选择适合微信、朋友圈或培训投屏的画幅；
- 不先问风格：根据医疗机构咨询场景默认采用清晰、可信、克制的视觉风格；
- 不先问文案：从用户请求和已审核事实中生成短文案；
- 中文长文案先生成画面，再自动排版叠字，避免生图模型直接生成错字；
- 同一需求默认输出一张主图，必要时附带一个适合聊天发送的简版；
- 输出后不自动发送、发布或写入 CRM。

## 四类核心资产

### 匿名案例图

结构：患者背景（脱敏）→ 当前顾虑 → 咨询动作 → 下一步 → 结果来源。

没有授权真实照片时使用图标、插画或抽象人物，不生成虚构患者肖像并称为真实患者。

### 咨询动作对比图

优先对比咨询行为，不对比虚构医疗效果：

- 普通回复 vs 优化回复；
- 只介绍项目 vs 先识别顾虑；
- 只问联系方式 vs 说明来源和用途；
- 模糊邀约 vs 给出可选择的下一步。

### 朋友圈海报

结构：一个主题 → 一个可信事实 → 一个低压力行动入口。避免堆砌疗效、价格、专家和紧迫性。

### 医院环境图

真实照片优先；AI 生成的环境必须作为示意素材使用，不得暗示为真实院区照片。

## 自动安全处理

不要求用户事前确认，但后台自动处理：

- 去除或替换姓名、电话、微信、头像、病历号和未授权身份信息；
- 将未经核验的疗效、治愈率、治疗周期和诊断结论改为中性表达；
- 将虚构的真实案例改为“案例示意”；
- 将虚构医院、医生和环境改为抽象或示意素材；
- 医疗判断、用药、检查和治疗结论不作为事实写入图中；
- 用户要求继续修改时直接重做，不重复询问同一确认问题。

## 交付说明

默认只给用户：成品图片、适用场景和一句简短说明。不要展示提示词、内部风险标签、知识库 ID 或复杂的审核过程。只有用户追问时，才解释某个事实为何被替换或标注为示意。
