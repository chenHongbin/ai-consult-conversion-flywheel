# v1.1：机构能力包写回、运行时加载与反馈闭环

## 核心变化

v1.0 解决“全量扫描和增量处理”；v1.1 解决“蒸馏结果真正改变后续回答”。

- 机构专属能力包保存在用户工作空间，不修改公共 Skill；
- 蒸馏 Agent 输出结构化 `candidate.json`；
- 候选按 ID 合并到版本化 `package.json`；
- 生成运行时 `runtime-context.md`；
- `active.json` 指向当前运行版本；
- 日常分析、回复、陪练和团队复盘优先加载 active 能力包；
- 管理者反馈写入 `feedback.jsonl`，进入下一轮增量蒸馏；
- 支持版本回滚，不删除旧版本和原始证据。

## 关键脚本

```text
commit_capability_candidate.py  候选合并、写回和发布
load_active_capability.py       日常运行时加载
record_capability_feedback.py   记录管理者反馈
rollback_capability.py          切换到上一版本
```

机构资料、真实录音、聊天记录和 IMA 内容仍然不会写进公共 Skill 或发布包。
