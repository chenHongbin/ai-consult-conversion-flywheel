# 咨询转化 Dream Cycle（v0.4）

## 核心循环

咨询 Skill 的持续迭代不是“把更多录音塞进模型”，而是一个可回溯的学习飞轮：

```text
新增资料
→ 识别与去重
→ 长图切片/OCR、录音转写
→ 案例标准化
→ 正向样本/反例/待确认分组
→ 批量分析与对照蒸馏
→ 生成候选能力包
→ 固定测试集回归
→ 发布新版本
→ 日常反馈回流
```

每轮都保留原始证据、处理清单、候选规则、测试结果和版本差异。不能因为一次批量处理成功就自动覆盖当前能力包。

外部资料的生命周期必须独立于 Skill：外部知识库、录音、聊天记录和图片是“用户本轮主动接入的输入”，不是默认记忆。它们不得被复制进 Skill 源码、通用参考资料或发布包；如需沉淀，只能在完成授权、脱敏、去机构化和用户明确纳入后，提炼为当前机构的抽象规则。

## 两种资料源

### 本地文件夹

首次初始化时由 `scripts/init_consult_workspace.py` 在用户指定的工作空间根目录下创建：

```text
咨询转化工作区/
├── 01_机构介绍/               用户放机构资料
├── 02_科室项目与服务/         用户放科室、项目和服务事实
├── 03_咨询流程与标准/         用户放 SOP、合规和流程
├── 04_优秀咨询案例/           用户放优秀录音和聊天
├── 05_普通失败与未预约案例/   用户放对照案例
├── 06_团队培训与反馈/         用户放培训、练习和复盘
├── 07_我的产出/               Skill 输出分析、话术和报告
├── 08_团队管理/               单主管团队、成员档案、会议、报表和自动化
└── _系统/                     Skill 自动维护处理过程和版本
```

用户不需要理解 `_系统`。转写、OCR、案例标准化、蒸馏候选、评估集和失败记录均在 `_系统` 中按子目录维护。

### IMA 知识库

使用 IMA 时记录知识库名称、科室/病种范围和同步文件夹。优先增量读取新文件，不重复下载全部内容。IMA 的限频、权限和笔记作者限制必须写入同步记录；失败条目进入 `_系统/失败记录/`，不影响其他条目继续处理。

## 批量蒸馏的五个阶段

1. **扫描**：生成文件清单、媒体类型、路径、哈希和新增/变更状态；
2. **标准化**：音频用 YouNavi 转写，长图先切片再 OCR，HTML/文档转成可检索文本；
3. **标注**：识别科室、病种、渠道、咨询阶段、结果标签、来源性质和授权状态；路径里的“已到/未到”只能作为待确认的结果线索；
4. **蒸馏**：批量对照优秀、普通、失败和高风险案例，提取行为—条件—效果，不摘录孤立金句；
5. **写回与发布**：让蒸馏 Agent 输出结构化候选，合并到机构能力包，跑固定测试集，通过后发布新版本并更新运行时指针，保留旧版本可回滚；
6. **运行与反馈**：日常分析先读取当前能力包，管理者的“保留/修改/废弃”反馈写入反馈队列，进入下一轮增量蒸馏。

## 每轮蒸馏的输出

每轮至少生成：

- `batch-manifest.jsonl`：本轮处理的案例清单；
- `distillation-candidates.md`：候选咨询动作、话术、流程和风险规则；
- `evidence-map.jsonl`：候选规则对应的案例和时间点/OCR位置；
- `review-queue.md`：科室、结果、授权、事实和合规待确认项；
- `eval-report.md`：固定测试集结果、回归失败和版本差异。

团队管理的结果反馈单独保留：每周生成员工管理报告，每月把一对一沟通与近四周过程量、结果数据合并复盘。员工管理报告只用于支持和改进行动，不自动写入绩效定级，也不能反向污染机构咨询能力包。

## 发布策略

自动处理可以自动生成候选版本。通过覆盖率、证据、反例、隐私、医疗边界和固定测试后，自动切换 `active.json`；失败时不影响旧版本。用户不需要理解版本号；如果用户说“回滚上一版”，只改变运行时指针，不删除任何资料。

## 周期运行

Skill 提供可重复执行的批处理脚本，但 Skill 本身不应偷偷创建系统定时任务。用户可以用 WorkBuddy 的定时能力、系统任务或手动触发：

```text
首次运行：扫描当前工作空间根目录的全部候选资料 → 完成全量转写/OCR/标准化 → 通过覆盖率闸门后生成候选蒸馏报告。

后续每周六：扫描当前工作空间根目录 → 按文件哈希只处理新增或变化资料 → 生成候选蒸馏报告 → 输出待发布提示。
```

周期任务只处理新增/变更文件，依据哈希去重；遇到权限、脱敏、OCR 或转写失败，只记录失败并继续其他资料。
