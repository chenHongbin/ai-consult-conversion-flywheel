# v0.3 发布说明

## 核心变化

v0.3 的目标是降低第一次使用门槛，同时把“赖老师分析 + 女娲式蒸馏 + 新人陪练”收敛到同一个单入口 Skill 中。

## 新增能力

- 主路径明确支持 WorkBuddy、Trae、Codex、Claude 和普通本地工作区；IMA 作为第二路径自动适配。
- 初始化时在用户选定的工作空间根目录下创建 `咨询转化工作区/`，不默认写入桌面或文档目录。
- 自动创建 7 个学员看得懂的资料文件夹和后台 `_系统` 文件夹。
- 首次只问机构/科室和资料来源两个问题，其他信息按需补充。
- 首次允许只用一条录音、一张聊天截图或一段文字跑通咨询复盘卡。
- 赖静茹老师方法论成为默认分析引擎，并允许前台直接显示。
- 增加张一鸣、梁文锋、马化腾、乔布斯、马斯克五张人物视角卡；人物名称只是易懂入口，实际调用抽象分析视角。
- 增加新人单动作 AI 陪练：学方法、练一轮、复盘重练。
- 增加本地运行环境和 IMA 凭证的无网络检测脚本。

## 目录

```text
咨询转化工作区/
├── 01_机构介绍
├── 02_科室项目与服务
├── 03_咨询流程与标准
├── 04_优秀咨询案例
├── 05_普通失败与未预约案例
├── 06_团队培训与反馈
├── 07_我的产出
└── _系统
```

## 设计边界

- 学员只安装一个 Skill；赖老师方法论、蒸馏器、陪练和人物视角都是内部能力。
- IMA 不是默认知识库，必须由当前用户主动选择；外部资料不进入 Skill 发布包。
- 人物视角不伪装成名人本人发言，不覆盖机构事实和医疗安全规则。
- 陪练不编造医生、价格、地址、疗效、治疗周期或活动信息。
- 新人默认只看到自己的训练反馈，不默认展示团队排名。

## 回归建议

1. 在普通本地工作区运行初始化脚本；
2. 检查 7 个中文文件夹和 `_系统` 是否生成；
3. 放入一条合成或已授权测试案例，验证复盘卡；
4. 验证“让乔布斯视角看一下”先走赖老师分析，再输出补充视角；
5. 验证陪练只训练一个动作，并能重练一次；
6. 验证无 IMA 凭证时仍可使用本地模式。
