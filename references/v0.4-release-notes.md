# v0.4 发布说明

v0.4 把 Skill 从“咨询分析与蒸馏框架”推进到“咨询动作、团队管理和结果验证”的工作流。

## 本轮实现

- 初始化工作区增加 `08_团队管理`，并自动创建员工档案、员工沟通、过程量、结果、团队报告和管理跟进六个子文件夹；
- 初始化时生成指标口径、团队基线和过程/结果数据模板；
- 增加每周团队报告脚本，支持 CSV、JSON、JSONL，输出员工过程量、咨询转化率、到院率、付费率、结果风险和数据缺口；
- 增加月度一对一沟通工作流，要求结合近四周数据和员工沟通记录输出一个支持或改进动作；
- 增加“咨询转化率翻倍、到院率翻倍”目标追踪，但明确区分目标、当前结果和真实对照验证，不把翻倍写成无条件保证；
- 修正测试集校验和环境检测脚本在旧版 Python 环境下的兼容问题。

## 本轮没有假装实现的部分

- 没有自动连接 CRM、微信或外部绩效系统；
- 没有自动读取或发布员工绩效结论；
- 没有用报告替代管理者的一对一沟通；
- 没有用结构化统计替代真实机构的受控转化实验；
- 没有把任何外部机构资料、IMA 测试资料或真实员工录音打包进 Skill。

## 推荐验收方式

先在本地初始化一个新工作区，放入脱敏的过程量和结果 CSV，再运行：

```text
python3 scripts/generate_team_report.py "咨询转化工作区" --start 2026-08-01 --end 2026-08-07
```

报告生成后，再由管理者补充员工一对一沟通摘要和本周唯一管理动作。真实“翻倍”结论必须等待机构基线、对照组和完整结果周期。
