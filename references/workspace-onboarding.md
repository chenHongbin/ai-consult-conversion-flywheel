# 首次使用向导（V2.1.1）

## 目标

让没有软件使用经验的咨询主管或一线咨询师在几分钟内完成四件事：让飞轮理解角色和机构作用域、建立本人或团队、创建标准工作区、用一条真实材料验证。用户看到首条价值后，再选择自动运行或手动模式。

## 前台交互

### 1. 先采访，确认后建立工作区

如果当前工作空间已有其他资料，自动做只读盘点，不移动、不改名、不上传原文件。当前选择的工作空间根目录就是首次全量扫描边界；Skill 在这里建立 `咨询转化工作区/` 和后台资料索引。

Skill 不默认写入桌面、文档、下载或其他未指定目录。

前台只说：

> 我先了解你的角色、机构和本人或团队，再用一条真实咨询验证。大约 5 分钟。

如果检测到当前空间已经有大量录音但没有机构资料，只在后台记录为后续接入提示，不能替换或提前打断第一问。首次前台仍然只问角色；完成设置后再说明可以先蒸馏咨询行为，机构事实稍后绑定。

### 2. 核心采访不超过 5 轮

1. 是自己做咨询，还是管理团队；
2. 机构名称、当前负责的科室或部门；
3. 日常最主要的工作和当前问题；
4. 一线确认本人，主管导入至少一名咨询师；
5. 上传一张微信长截图、一通录音或一段文字作为首条验证。

采访结束只做一次汇总确认。渠道、顾虑、输出偏好、额外红线、考核口径和学习目标在真正影响当前任务时渐进补充。详细流程见 [v2.1.1-onboarding-runtime.md](v2.1.1-onboarding-runtime.md)。

### 3. 给用户八个能看懂的文件夹

```text
01_机构介绍
02_科室项目与服务
03_咨询流程与标准
04_优秀咨询案例
05_普通失败与未预约案例
06_团队培训与反馈
07_我的产出
08_团队管理
```

`08_团队管理` 第一版只建立一个主管团队，前台只显示“成员、团队会议、团队数据、团队报告”四个入口；日期、资料类型和后台归档由 Skill 自动完成。管理者每周可以说“生成本周团队报告”；默认每月进行一次员工一对一沟通，报告只提取与工作相关的事实。首次建立团队时询问主管姓名和成员名单，成员文件夹使用 `员工编号_姓名`。

用户不需要准确分类。放错位置时，Skill 自动识别并在后台建立正确索引；只有机构、科室、结果和是否允许团队学习这三个关键字段异常时才追问。

### 4. IMA 适配

- 在 WorkBuddy、Trae、Codex 或普通本地环境中：先检查是否已有 IMA 凭证；没有时不阻塞本地模式。
- 在 IMA 原生环境中：使用宿主提供的登录上下文，不重复索取 Client ID 和 API Key。
- 接入 IMA 后：先列出知识库名称和简介，让用户选择；不根据历史示例或默认名称猜测知识库。
- 读取知识库前：记录当前用户选择、用途、授权状态和科室范围。

### 5. 夜间自动化

首条真实报告完成并得到用户基本认可后，才申请一次明确调度授权。默认每天 22:30 调用 `scripts/run_nightly_cycle.py` 建立去重、可恢复的任务，再用 `scripts/daily_review.py` 分批领取、提交逐案分析并聚合员工/团队/训练报告。只有宿主返回活动状态、真实自动化 ID、匹配时间和工作区后，`scripts/onboarding.py verify-automation` 才标记开启；否则进入手动模式。电脑关机或 Agent 未运行时，下一次任务自动补跑。

### 6. 第一次价值交付

不要求用户先整理几十条资料。首次设置直接用一条真实微信、录音或文本生成正式“咨询复盘卡”，验证机构、员工归属、OCR/转写和分析判断。第一次说“蒸馏销冠”时，再自动扫描当前工作空间并处理全部候选资料。首次全量蒸馏完成后提示：

> 如果你愿意，把更多优秀、普通或未预约案例放进对应文件夹，我可以继续帮你蒸馏成专属能力。

### 7. 没有机构知识库时

允许直接从录音开始，但必须走“临时咨询能力包”路径：先盘点、转写、标签、优秀与失败对照、候选行为卡、固定测试，再影子运行。没有机构资料时，不得生成真实价格、医生、地址、疗效、治疗周期或机构流程。完整的逐步提示词见 [initialization-and-distillation-prompts.md](initialization-and-distillation-prompts.md)。

## 后台状态

用户只看到“准备中、可以分析、正在学习、已更新”四种状态。技术处理记录放在 `_系统/`，包括转写、OCR、案例标准化、蒸馏候选、评估和版本记录。

## 失败处理

任何资料读取失败都不让用户理解 API、媒体 ID 或游标。只显示：

- 可以继续使用其他资料；
- 这份资料暂时无法读取；
- 你可以稍后重试或换一种方式提供。
