# 团队档案、命名与夜间 Dream Cycle

## 适用范围

v0.7 第一版只支持一个主管团队。一个 Skill 工作区对应一个主管、一个团队和一组成员；以后扩展多团队时再增加团队级隔离，不在第一版混用多个主管的数据。

## 目录规范

```text
08_团队管理/
├── 01_成员/
│   ├── A001_张三/
│   │   ├── 01_今天放这里/
│   │   ├── 02_历史资料/
│   │   └── 03_个人报告/
│   └── A002_李四/
├── 02_团队会议/
│   ├── 01_今天放这里/
│   └── 02_会议报告/
├── 03_团队数据/
│   └── 01_今天放这里/
├── 04_团队报告/
│   ├── 01_日报/
│   ├── 02_周报/
│   ├── 03_月报/
│   └── 04_数据看板/
```

用户每天只需要把资料放入对应成员的 `01_今天放这里`。历史资料放入 `02_历史资料`，不用手动建立日期和类型目录。夜间任务负责识别员工、日期、资料类型、统一命名和后台归档；原始文件不覆盖、不删除。

后台归档由 Skill 自动维护，用户不需要打开或修改：

```text
_系统/
├── 团队档案/
│   └── A001_张三/
│       └── 2026/08/2026-08-09/
│           ├── 01_咨询录音/
│           ├── 02_微信聊天/
│           └── 03_一对一沟通/
├── 团队会议/YYYY/MM/YYYY-MM-DD/会议类型/
├── 团队数据/YYYY/MM/YYYY-MM-DD/
└── 团队自动化/
    ├── 01_待处理队列/
    └── 02_运行日志/
```

前台原文件始终保留；后台归档是可追溯副本，不是移动或删除。`团队档案/归档索引.json` 记录原文件、归档文件、哈希、日期来源和资料类型，避免同一文件重复进入蒸馏队列。

## 文件命名规范

普通咨询资料：

```text
YYYY-MM-DD__员工编号__资料类型__科室-病种__渠道__结果__序号.扩展名
```

示例：

```text
2026-08-09__A001__电话录音__皮肤科-银屑病__广告__已预约__001.m4a
2026-08-09__A001__微信聊天__皮肤科-银屑病__医生IP__未预约__002.html
2026-08-09__A001__一对一沟通__主管A__月度沟通__001.m4a
```

团队会议资料：

```text
YYYY-MM-DD__团队名称__会议类型__主题__序号.扩展名
```

示例：

```text
2026-08-09__团队A__早会__昨日咨询复盘__001.m4a
2026-08-09__团队A__周复盘__预约到院分析__001.m4a
```

规则：

- 日期使用真实咨询或会议日期；不知道时写“日期待确认”；
- 员工使用 `员工编号_姓名`，例如 `A001_张三`；
- 患者只能使用匿名案例 ID，不能出现姓名、电话、微信号或病历号；
- 科室、病种、渠道和结果不确定时写“待确认”；
- 不使用空格、斜杠和特殊符号；
- 私有团队报告可以显示员工姓名，发布包、外部案例和对外分享必须删除员工姓名。

## 个人纵向比较

每次夜间分析按同一员工比较：

```text
当日 vs 上周同日
本周 vs 上周
本月 vs 上月
```

比较四层：

1. 过程量：有效线索、有效咨询、留资、回访、预约；
2. 结果：到院、付费、退款、投诉；
3. 行为：阶段判断、提问、顾虑回应、推进节奏、回访动作；
4. 成长：上期辅导动作是否执行，是否在新案例中稳定出现。

每名员工每个周期只生成一个重点提升技能，不能给十条泛泛建议。

## 会议管理

会议录音独立于员工咨询档案。夜间分析会议时输出：主题、结论、团队共性问题、决定事项、负责人、截止日期和下一次复查内容。会议观点可以作为管理者观察，但未经案例证据支持，不得直接升级为团队规则或员工绩效结论。

## 夜间 Dream Cycle

WorkBuddy、Codex 或其他 Agent 的定时任务在获得用户授权后默认每天 22:30 触发：

1. 读取 `_系统/来源配置.json` 和自动化配置；
2. 扫描成员 `01_今天放这里`、`02_历史资料`、团队会议和团队数据入口；
3. 用文件哈希去重，跳过临时文件和仍在上传的文件；
4. 把稳定的新资料复制到隐藏个人档案、隐藏会议档案或隐藏数据档案，原文件不移动；
5. 在 `_系统/每日复盘` 建立可恢复任务；Agent 分批领取，音频进入 YouNavi 转写，长图进入切片/OCR，HTML/聊天进入文本解析，表格进入数据校验；
6. 所有有效咨询生成标准逐案报告，风险、流失、关键阶段、新问题和典型案例进入深析；
7. 失败、隔离和待确认状态写入任务投影与追加式事件，不阻塞其他资料；
8. 生成逐案报告、员工日报、团队日报和单动作训练卡，分别写入团队报告和成员个人报告；
9. 聚合四类管理记录，重建 `04_团队报告/04_数据看板/咨询管理工作台.html`；
10. 在夜间结果中返回工作台路径、生成时间、数据完整性、待分析数和失败数；
11. 只生成候选能力和辅导建议，不自动发布能力包，不自动写入绩效系统。

文件必须满足“最后修改时间超过稳定等待时间”或用户明确标记完成，才能进入夜间处理。电脑关机或 Agent 未运行时，下一次任务自动补跑，不重复处理已完成文件。

## 数据来源

飞书文档、WPS 文档、腾讯文档、本地 Excel 都统一进入 `03_团队数据/01_今天放这里` 的 CSV/XLSX/JSON 口径。Skill 优先使用宿主提供的连接器；没有连接器时，用户把表格导出到本地工作区，不能假设 Skill 可以直接读取任意云文档权限。
