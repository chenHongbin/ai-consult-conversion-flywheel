# v0.5 发布说明

v0.5 把团队管理从“按资料分类”升级为“单主管团队的成员纵向档案”。

## 本轮实现

- 第一版一个 Skill 只支持一个主管团队；
- 初始化支持主管姓名和 `员工编号_姓名` 成员名单；
- 目录按“主管—成员—年/月/日—资料类型”组织；
- 增加团队会议目录：早会、晚会、周复盘、月度盘点和专项培训；
- 增加团队日报、周报、月报和看板目录；
- 增加统一文件命名规则，禁止在患者资料文件名中出现姓名、电话、微信号和病历号；
- 私有团队报告可以显示员工姓名，发布包和对外材料必须去除员工姓名；
- 增加 `run_nightly_cycle.py`，供 WorkBuddy、Codex 等定时 Agent 在 22:00 扫描新增资料、哈希去重并生成任务队列；
- 团队数据入口兼容本地 Excel/CSV，以及飞书、WPS、腾讯文档导出的表格；
- 周报脚本支持日报、周报、月报输出目录。

## 夜间任务边界

扫描脚本负责稳定性检查、类型识别、去重、排队和运行日志；转写、OCR、咨询分析、会议纪要和看板生成由被唤醒的 Agent 继续执行。失败任务不阻塞其他任务，电脑或 Agent 关闭后下一次自动补跑。

夜间循环不会自动发布能力包、自动做人事定级、自动写入绩效系统、自动发送微信或对外发布内容。
