# V2.1 发布说明：每日全量咨询复盘与员工辅导闭环

V2.1 把“材料进入队列”升级为“可恢复地完成逐案复盘并生成员工、团队和训练输出”。

主要变化：

- 新增六层对象和稳定 ID；
- 新增患者归并建议与主管确认；
- 新增带租约、重试、隔离和幂等的分析任务；
- 新增逐案、员工、团队、训练四层交付；
- 新增员工/团队证据门槛；
- 新增旧工作区增量迁移；
- 新增 V2.1 ConsultBench 自动化回归；
- 明确 V2.1 只承诺行为改善和管理提效，不宣称已验证转化提升。

V2.1 的夜间脚本仍不直接调用某个固定模型 API。Agent 主机领取任务、执行 OCR/转写与语义分析，再通过统一合同提交结果；这样核心队列和报告协议可以跨 WorkBuddy、Codex、Claude 和 Trae 使用。
