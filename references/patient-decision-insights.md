# 患者决策洞察与 AI 陪练（v1.5）

## 目标

患者洞察不是给患者贴标签，而是帮助咨询师在当前对话不确定时选择下一步动作。

```text
原始录音/微信/私信
→ 转写、OCR、消息顺序
→ 去重后的咨询案例
→ 八步法阶段与疑义意图
→ 患者决策状态原型
→ 条件化咨询动作
→ 脱敏合成陪练场景
→ 训练反馈与真实结果
→ 下一轮 Dream Cycle
```

## 与现有双轨的关系

- **咨询能力包**：怎么判断、怎么提问、怎么回应、怎么推进。
- **机构知识包**：机构、科室、医生、项目、价格、流程等已确认事实。
- **患者决策洞察层**：群体级行为观察和条件索引，不是第三个事实库。
- **运行时状态**：当前这一个对话的临时假设，用完即止，不跨患者复用。

机构事实不能由患者画像推断出来；患者洞察也不能把个案叙事写进团队包。

## 决策状态卡

第一版只维护 5—8 个状态，例如费用/价值比较、既往失败后的效果担忧、医院/医生信任验证、时间距离约束、家属决策未参与、预约后犹豫、隐私与拒绝留资、需要转医生的临床问题。

每张卡至少包含：

```text
state_id
scope: 机构/科室/病种/渠道/时间窗口
observable_signals: 可观察原话或行为
common_doubt_intents: 关联疑义
latent_concern_hypothesis: 最多两个候选解释，必须标记为假设
validation_question: 下一句先确认什么
recommended_next_action: 确认后做什么
support_case_ids / counterexample_ids
independent_dedup_clusters / denominator
label_confidence / behavior_confidence / outcome_confidence
clinical_boundary / privacy_risk / review_status
```

禁止沉淀收入、职业、学历、性格、心理、疾病严重程度、支付能力、成交潜力或“高价值/难成交患者”等标签。原话是事实，隐藏顾虑只是待验证假设。

## 常见 100 问与新人 200 问

`faq_100` 是疑义意图目录的展示视图，不是孤立话术表。每条记录要说明出现范围、独立案例簇数量、反例、阶段、证据和安全出口。

`training_200` 是培训视图，由“疑义意图 + 八步法阶段 + 机构确认事实 + 销冠动作 + 失败反例”生成。没有证据的题目不能发布。

统一回答结构：

```text
患者表面问题 → 已观察事实 → 候选顾虑 → 先问一个问题 → 安全回应 → 下一步 → 禁止表达/转人工条件
```

## AI 陪练

陪练只使用脱敏、聚合后的状态卡生成合成患者，不读取真实患者的隐性画像。

一轮只练一个动作：患者说一句 → 学员回复 → 继续 2—4 轮 → 指出一个关键问题 → 学员重答。前台只显示“你做对的、你漏掉的、下一句建议”。

陪练只评价可观察行为：阶段判断、倾听提问、顾虑回应、机构事实使用、医疗/隐私边界、下一步动作。不评价人格、智力、忠诚度或患者成交概率，也不直接用于绩效和人事决定。

## 发布门槛

只有同时具备授权/脱敏、独立案例簇、证据与反例、适用范围、固定测试、隐私审核和管理者确认，患者洞察候选才可进入 active。小样本只能写“本批观察到”，不能写“患者通常”或“这类人都”。
