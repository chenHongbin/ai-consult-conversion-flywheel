# v1.2：团队 Skill 发布与每周同步

## 核心目标

主管端每天学习，团队端每周稳定更新。主管不把原始患者资料发给团队，而是把通过测试的基础 Skill 与机构专属能力包封装成一个团队 `.skill`。

## 新增能力

- `build_team_skill_package.py`：生成“基础 Skill + 已审核机构能力包”的团队发布包；
- 团队包内置 `institution-pack/`，成员安装后可直接读取机构能力；
- 团队包生成前自动检查患者身份信息、原始资料和主管私有工作区是否被带入；
- 团队成员反馈回到主管端 `feedback.jsonl`，进入下一轮 Dream Cycle；
- 主管端和团队端分离，候选规则不会直接发送给全员；
- 继续保留版本、发布清单和回滚能力。

## 发布命令

```bash
python3 scripts/build_team_skill_package.py <工作空间根目录> \
  --output-dir <团队发布目录> \
  --institution <机构名称> \
  --department <科室名称>
```
