# v1.7 发布说明：咨询视觉弹药与嵌入式医疗生图

## 核心变化

v1.7 把生图从“额外工具”变成咨询分析后的视觉弹药层。对话分析确定患者阶段、顾虑和下一步动作后，Skill 可以继续产出：

1. 朋友圈短文案；
2. 微信下一步跟进文案；
3. 推荐视觉类型和生图提示词；
4. 直接生成一张适配当前渠道的主图；
5. 图片用途、事实来源、QA 和反馈回填。

## 嵌入方式

现有 `medical-image-studio` 已嵌入：

```text
skills/medical-image-studio/
├── SKILL.md
├── references/
├── assets/
└── scripts/
```

它是主 Skill 的内部引擎，不是学员需要单独安装的第二个 Skill。它保留老张 API / HiAPI 路由、项目契约、视觉路由、比例和文字容量控制、dry-run、pilot 和 QA。

## 用户体验

用户可以直接说：

- “分析这段咨询，并给我朋友圈文案和配图。”
- “患者担心以前治疗没效果，给我一张微信跟进案例示意图。”
- “做一张门诊环境氛围图。”
- “把这条录音做成团队培训视觉卡。”

Skill 不要求用户在每次出图前确认；用户可以继续说“换一种风格”“文字短一点”“改成朋友圈比例”进行重做。图片不会自动发送微信、发布朋友圈或写入 CRM。

## 事实边界

- 没有授权真实照片时，案例图使用匿名案例示意或过程示意；
- 没有真实医院照片时，环境图使用环境示意，不冒充真实院区；
- 机构名称、医生、价格、地址、活动和服务只来自已审核机构知识；
- 不生成或包装虚假的真实患者前后疗效、医生身份、医院客流、患者证言或资质；
- 当前嵌入引擎的服务商适配器以文生图为主，图生图需要后续适配参考图上传接口，不能虚构已经使用了本地图片。
