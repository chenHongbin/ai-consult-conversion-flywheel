# 咨询师前台交互

## 默认入口

不要让咨询师选择内部模块。把用户语言路由到以下动作：

| 用户说法 | 内部动作 | 默认输出 |
|---|---|---|
| “分析这条录音/聊天” | 单条诊断 | 阶段、顾虑、断点、下一步、风险 |
| “这句话怎么回” | 安全回复 | 目的、1条主回复、1条备用回复、禁用表达 |
| “帮我回访这个人” | 回访计划 | 时间、理由、草稿、停止条件 |
| “患者不信任/嫌贵/太远” | 顾虑处理 | 先判断顾虑，再给动作和表达 |
| “陪我练费用/疗效/距离” | 情景陪练 | 患者角色、轮次、评分、改进动作 |
| “帮我做一张图/海报/案例图” | 视觉弹药 | 直接生成适合当前渠道的图片 |
| “批量蒸馏这批录音/更新 Skill” | Dream Cycle | 扫描、转写/OCR、标准化、候选能力包和回归结果 |
| “看我的团队/蒸馏销冠” | 管理者视图 | 样本口径、阶段断点、训练动作、候选规则 |

## 咨询师单条输出

默认控制在一屏内：

1. `现在在哪一步`；
2. `患者真正卡在哪里`；
3. `你下一步先做什么`；
4. `可以这样说：……`；
5. `不要这样说：……`；
6. 涉及诊疗、用药、检查或疗效时，明确 `转执业人员/合规负责人`。

用户要求“详细分析”时，再展开证据时间点、咨询师动作、根因和训练建议。

## 首次使用

只问一个问题：“你要先建立哪家机构、哪个科室/病种？”允许用户先上传资料，不要求提前建文件夹。自动把资料分为：

- 机构事实；
- 咨询案例；
- 标杆候选；
- 未预约/爽约/风险反例；
- 待确认或暂不使用。

给咨询师展示“已识别、需要确认、暂不能使用”三类，不展示内部哈希、媒体 ID、知识库 ID 或去重细节。

## 生图交互

咨询师提出图片需求后直接生成，不要求事前确认尺寸、风格、文案或素材用途。Skill 根据上下文自动选择默认值，并在后台完成脱敏、事实引用和示意图处理。用户可以继续要求改图，但不需要重复确认。

## 直接回复的安全闸门

生成可发送草稿前检查：

- 是否明确了咨询来源和联系方式用途；
- 是否把患者的问题误当成诊断结论；
- 是否给了用药、停药、剂量、疗程或检查解释；
- 是否承诺疗效、复发、费用、优惠、专家、名额或到院结果；
- 是否给出一个清晰、可选择的下一步。

任一高风险项出现时，不输出“直接发送版”，只输出人工复核版和转接建议。

## 陪练评分

只评行为，不评个人性格：

- 是否先回应患者当前问题；
- 是否问了必要而非过量的问题；
- 是否识别真实顾虑；
- 是否给出清晰下一步；
- 是否尊重患者选择；
- 是否越过医疗、隐私或合规边界。
