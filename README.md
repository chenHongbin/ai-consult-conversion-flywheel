# AI咨询转化飞轮

蒸馏销冠，复制团队，提升到院。

这是一个面向民营医疗机构咨询师与咨询管理者的单入口 AI Skill。它把机构初始化、咨询/录音/微信分析、长图切片 OCR、YouNavi 转写、案例蒸馏、AI 陪练、团队管理、夜间 Dream Cycle 和持续能力升级放在同一个入口后面。

## 核心循环

```text
机构资料初始化
    ↓
优秀咨询案例蒸馏
    ↓
日常咨询分析与陪练
    ↓
团队辅导、会议复盘与数据分析
    ↓
沉淀新案例，持续更新机构能力包
```

## 支持环境

- WorkBuddy、Trae、Codex、Claude；
- 普通本地工作区；
- IMA 知识库作为可选资料源。

## 隐私与开源边界

本仓库不包含任何机构真实知识库、真实录音、微信聊天记录、患者资料、IMA 示例内容、API Key 或 Client ID。使用时产生的机构资料只保存在用户自己的工作区，不会自动进入通用 Skill 或发布包。

医疗判断、诊断、治疗建议和疗效承诺不由本 Skill 替代医生完成；咨询分析和生成内容应遵守使用机构的审核与合规要求。

## 安装

下载发布包 `AI咨询转化飞轮_v0.9.skill`，在支持 Skill 的 Agent 产品中安装。安装后直接说：

> 第一次使用，帮我建立机构和咨询转化工作区。

技术目录标识保留为 `medical-consult-conversion-coach`，用于兼容既有安装和后续升级。
