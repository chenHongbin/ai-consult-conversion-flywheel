# AI咨询转化飞轮

> 面向民营医疗机构咨询主管、咨询总监和机构负责人的咨询团队管理与能力复制系统。一线咨询师也可以用它分析咨询、生成回复、训练和制作跟进素材。

AI咨询转化飞轮 v2.0 不再把“生成一份对话分析报告”当作终点。它从一通录音、一段微信或一张截图开始，帮助主管发现团队断点、提炼销冠动作、形成训练任务、复查普通咨询师的新样本，并观察预约、到院与人效变化。

支持 WorkBuddy、Trae、Codex、Claude 和其他支持 Skills 的 Agent，也支持普通本地工作区和可选的 IMA 知识库。

## 它解决什么问题

| 真实处境 | 你会得到 |
| --- | --- |
| 主管每天资料很多，不知道先处理什么 | 今日唯一团队断点、P0/P1/P2 待办、证据入口和复查标准 |
| 分析报告很多，但没有形成管理动作 | 患者推进、员工辅导、团队学习三层结论 |
| 不知道患者为什么不回复、没预约或没到院 | 沟通阶段、真实顾虑和流失节点诊断 |
| 患者说“太贵”“担心没效果”“不信任医院” | 顾虑类型、验证问题、安全回应和下一步动作 |
| 咨询师知道要回访，但不知道什么时候、为什么回访 | 分阶段回访计划、微信话术和停止条件 |
| 销冠经验在录音里，却无法复制给新人 | 销冠完整销售逻辑、阶段动作卡和 AI 陪练任务 |
| 团队主管每天听录音、做复盘、追踪员工进步 | 本地咨询管理工作台、员工单动作训练和复查队列 |
| 咨询师需要临时制作朋友圈或微信跟进素材 | 文案、案例示意、医院环境图、培训视觉卡和配图提示词 |
| 团队能力更新后，一线成员各自的经验容易丢失 | 团队运行层与个人成长层合并，更新团队但保留个人积累 |

## 快速开始

主管安装完成后，直接说：

```text
开始今天的工作。
复核今日重点。
生成晨会训练。
辅导这个员工。
复盘今天。
刷新咨询管理工作台。
```

一线咨询师直接说：

```text
分析这段微信，告诉我患者现在处于哪个阶段，为什么没有继续回复。

患者说费用太贵，帮我判断他真正担心什么，并写出下一句微信回复。

患者已经爽约两次，帮我设计一次合适的回访。

陪我练一次“担心过去治疗失败”的患者，只训练一个动作。
```

如果用户还没有机构资料或销冠蒸馏，基础咨询运行时也可以直接工作。它会使用通用咨询转化八步法，但不会编造本机构的价格、医生、地址、项目、疗效或治疗周期。

初始化本地资料时，Skill 只创建一个标准容器 `咨询转化工作区/`，并在其中生成截图所示的 `01_机构介绍` 到 `08_团队管理`、`_系统` 和 `README_先看这里.md`。初始化结束后会自动校验目录清单；没有通过校验，不会报告“初始化完成”。

## 咨询主管每日经营闭环

```text
发现团队断点
→ 找到优秀对照
→ 提炼销冠动作
→ 生成训练任务
→ 一线执行
→ 复查新样本
→ 验证行为和经营结果
→ 沉淀团队正式能力
```

本地工作台固定呈现六个模块：今日管理结论、今日管理待办、今日训练主题、重点员工与辅导进度、团队结果快照、女娲学习与能力复制。页面完全自包含、断网可用、只读；主管通过 Skill 指令更新任务，然后重建页面。

```bash
# 初始化与校验
python3 scripts/init_consult_workspace.py <目标目录> --name 咨询转化工作区
python3 scripts/verify_consult_workspace.py <目标目录>

# 生成或刷新工作台
python3 scripts/generate_management_dashboard.py <工作区> --period today --date YYYY-MM-DD

# 记录主管动作
python3 scripts/record_management_action.py <工作区> --task-id <任务ID> --event complete --note <说明>

# 一键创建完整的合成演示
python3 scripts/create_demo_management_workspace.py <目标目录>
```

生成页面位于：

`08_团队管理/04_团队报告/04_数据看板/咨询管理工作台.html`

## 基础运行时：不蒸馏也能用

AI咨询转化飞轮不是安装后只能等待资料蒸馏的空壳 Skill。它自带基础咨询运行时，安装后即可完成：

- 咨询转化八步法分析；
- 患者阶段判断；
- 真实顾虑识别；
- 费用、效果、信任、距离、时间和家人意见处理；
- 流失节点诊断；
- 到院前推进；
- 爽约和分阶段回访；
- 新人单动作陪练；
- 微信跟进文案和咨询视觉素材。

基础运行时的边界是：它提供通用咨询转化能力，不自动假设某家机构的具体事实。

## 蒸馏后：变成机构自己的咨询转化 Skill

主管第一次说“蒸馏销冠”或“更新咨询能力”时，Skill 会递归扫描当前工作空间，处理：

- 机构介绍、科室项目、医生和服务资料；
- 电话录音、微信聊天、私信和聊天截图；
- 长图切片与 OCR 结果；
- YouNavi 录音转写结果；
- 优秀、普通、失败、爽约和未到院案例；
- 团队会议、员工沟通和过程/结果数据。

蒸馏的主产物不是几句金句，而是可以被普通咨询师复制、被新样本验证的团队动作：

```text
销冠完整销售逻辑
    ↓
阶段判断与关键动作
    ↓
顾虑处理与流失修复
    ↓
新人陪练与团队辅导
    ↓
机构专属咨询转化能力包
```

每轮蒸馏同时沉淀三条证据链：

1. 个性化服务链：患者透露什么，咨询师如何识别、确认并提供针对性服务；
2. 安心感形成链：患者不确定什么，咨询师如何用事实、选择和路径降低不确定性；
3. 团队复制链：销冠动作如何被训练、采用、复查，并在普通咨询师新样本中稳定出现。

能力固定按 `候选经验 → 可训练动作 → 行为已验证 → 结果已验证 → 团队正式能力` 晋升。没有预约或到院数据时，只能验证行为，不宣称转化提升。

## 团队版与个人版

主管和一线使用同一个 AI咨询转化飞轮，但成长层不同：

```text
主管新增录音/聊天/数据
        ↓
团队蒸馏与审核
        ↓
发布 Team-v1.x
        ↓
一线安装更新
        ↓
继续分析自己的案例与训练
        ↓
形成 Personal-v0.x
```

团队更新时：

- 团队正式规则会更新；
- 个人历史案例和训练记录保留；
- 个人有效经验继续保留；
- 与新团队规则冲突的个人规则会标记为待重新验证；
- 个人经验不会未经主管审核自动进入团队规则。

## Dream Cycle

AI咨询转化飞轮的持续成长逻辑是：

```text
新增录音/微信/机构资料
        ↓
自动转写、OCR、去重和结构化
        ↓
识别团队断点与优秀对照
        ↓
生成训练任务并复查新样本
        ↓
验证行为和经营结果
        ↓
晋升并发布新的团队能力
        ↓
重建主管本地工作台
        ↺
```

IMA 资料源支持先建立清单、按价值排序、受限读取、配额感知、断点续传和受控缓存；IMA 限额不会阻塞本地资料处理。

## 隐私与安全边界

- 原始录音、微信聊天、截图和患者资料不进入公开 Skill 包；
- 外部 IMA 知识库不会被写入 Skill 默认内容；
- 患者姓名、电话、微信、病历和头像不会进入团队发布包；
- 未确认的价格、医生、地址、疗效、周期和活动不会被编造；
- 患者洞察只保留群体级决策状态，不生成患者个人画像；
- 不自动发送微信、不自动进行临床诊断、不自动做员工绩效定级；
- 生图能力必须由用户按照所在机构的审核要求使用，不能把虚构素材当作真实患者案例。
