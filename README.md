# AI咨询转化飞轮

> 面向民营医疗机构咨询师与咨询管理者的 AI 咨询转化教练。把一段电话、微信、私信、录音或团队资料交给 Agent，得到清晰的阶段判断、顾虑诊断、下一步动作和可直接使用的沟通素材。

AI咨询转化飞轮只需要安装一个 Skill。它内部会根据用户当前的问题，自动选择患者沟通诊断、费用异议、到院推进、回访、陪练、销冠蒸馏或团队管理等专项能力。

支持 WorkBuddy、Trae、Codex、Claude 和其他支持 Skills 的 Agent，也支持普通本地工作区和可选的 IMA 知识库。

## 它解决什么问题

| 真实处境 | 你会得到 |
| --- | --- |
| 不知道患者为什么不回复、没预约或没到院 | 沟通阶段、真实顾虑和流失节点诊断 |
| 患者说“太贵”“担心没效果”“不信任医院” | 顾虑类型、验证问题、安全回应和下一步动作 |
| 咨询师知道要回访，但不知道什么时候、为什么回访 | 分阶段回访计划、微信话术和停止条件 |
| 销冠经验在录音里，却无法复制给新人 | 销冠完整销售逻辑、阶段动作卡和 AI 陪练任务 |
| 团队主管每天听录音、做复盘、追踪员工进步 | 员工纵向分析、团队报告、会议复盘和辅导建议 |
| 咨询师需要临时制作朋友圈或微信跟进素材 | 文案、案例示意、医院环境图、培训视觉卡和配图提示词 |
| 团队能力更新后，一线成员各自的经验容易丢失 | 团队运行层与个人成长层合并，更新团队但保留个人积累 |

## 快速开始

安装完成后，不需要先学会“知识库、蒸馏、路由、能力包”等概念，直接把问题交给总入口：

```text
分析这段微信，告诉我患者现在处于哪个阶段，为什么没有继续回复。

患者说费用太贵，帮我判断他真正担心什么，并写出下一句微信回复。

患者已经爽约两次，帮我设计一次合适的回访。

陪我练一次“担心过去治疗失败”的患者，只训练一个动作。
```

如果用户还没有机构资料或销冠蒸馏，基础咨询运行时也可以直接工作。它会使用通用咨询转化八步法，但不会编造本机构的价格、医生、地址、项目、疗效或治疗周期。

初始化本地资料时，Skill 只创建一个标准容器 `咨询转化工作区/`，并在其中生成截图所示的 `01_机构介绍` 到 `08_团队管理`、`_系统` 和 `README_先看这里.md`。初始化结束后会自动校验目录清单；没有通过校验，不会报告“初始化完成”。

## 一个总入口，多个隐藏专项能力

用户只安装：

```text
AI咨询转化飞轮
```

内部专项能力包括：

| 工作目标 | 内部专项能力 | 常见产出 |
| --- | --- | --- |
| 分析电话、微信、私信和录音 | 患者沟通诊断 | 阶段判断、流失节点、复盘报告 |
| 处理费用、效果和信任问题 | 顾虑判断与回应 | 验证问题、共情表达、回应话术 |
| 推进预约和到院 | 到院前推进 | 邀约动作、时间确认、防爽约提醒 |
| 处理距离、时间和家人意见 | 决策阻力处理 | 阻力判断、推进策略、跟进素材 |
| 处理爽约、未到院和失联 | 爽约与分阶段回访 | 回访目的、回访文案、停止条件 |
| 训练新人和强化单个动作 | 新人单动作陪练 | 患者角色、多轮互动、一个关键反馈 |
| 分析优秀录音和失败录音 | 销冠完整链路蒸馏 | 销冠逻辑、流程、动作卡、候选能力 |
| 更新机构专属能力 | Skill 版本迭代 | 测试、审核、发布、回滚 |
| 管理员工、会议和过程数据 | 团队管理与复盘 | 周报、月报、一对一辅导建议 |
| 生成咨询配图和跟进素材 | 咨询视觉与跟进素材 | 朋友圈文案、微信文案、图片提示词 |
| 按患者阶段和顾虑选素材 | 视觉与内容素材编译器 | 主素材、备选素材、组合包、CTA 和反馈记录 |

已经知道自己要做什么时，也可以直接说专项名称，例如：

```text
进入费用异议模式。
进入爽约回访模式。
进入新人陪练模式。
进入销冠完整链路蒸馏模式。
```

正常使用时不需要输入命令，也不需要自己选择文件或模块。

## 基础运行时：不蒸馏也能用

AI咨询转化飞轮不是安装后只能等待资料蒸馏的空壳 Skill。它自带基础咨询运行时，安装后即可完成：

- 咨询转化八步法分析；
- 患者阶段判断；
- 真实顾虑识别；
- 费用、效果、信任、距离、时间和家人意见处理；
- 流失节点诊断；
- 到院前推进；
- 爽约和分阶段回访；
- 新人单动作陪练；
- 微信跟进文案和咨询视觉素材。

基础运行时的边界是：它提供通用咨询转化能力，不自动假设某家机构的具体事实。

## 蒸馏后：变成机构自己的咨询转化 Skill

主管第一次说“蒸馏销冠”或“更新咨询能力”时，Skill 会递归扫描当前工作空间，处理：

- 机构介绍、科室项目、医生和服务资料；
- 电话录音、微信聊天、私信和聊天截图；
- 长图切片与 OCR 结果；
- YouNavi 录音转写结果；
- 优秀、普通、失败、爽约和未到院案例；
- 团队会议、员工沟通和过程/结果数据。

蒸馏的主产物不是几句金句，而是：

```text
销冠完整销售逻辑
    ↓
阶段判断与关键动作
    ↓
顾虑处理与流失修复
    ↓
新人陪练与团队辅导
    ↓
机构专属咨询转化能力包
```

每轮蒸馏同时沉淀三类内容：

1. 咨询能力：销冠逻辑、流程、阶段动作、顾虑处理和失败避坑；
2. 机构知识：机构、科室、项目、医生、服务、优势和已确认事实；
3. 患者洞察：群体级常见疑义、决策状态、流失节点和合成陪练场景。

所有机构事实和团队规则都经过候选、审核、测试后才进入正式运行时。

## 团队版与个人版

主管和一线使用同一个 AI咨询转化飞轮，但成长层不同：

```text
主管新增录音/聊天/数据
        ↓
团队蒸馏与审核
        ↓
发布 Team-v1.x
        ↓
一线安装更新
        ↓
继续分析自己的案例与训练
        ↓
形成 Personal-v0.x
```

团队更新时：

- 团队正式规则会更新；
- 个人历史案例和训练记录保留；
- 个人有效经验继续保留；
- 与新团队规则冲突的个人规则会标记为待重新验证；
- 个人经验不会未经主管审核自动进入团队规则。

## Dream Cycle

AI咨询转化飞轮的持续成长逻辑是：

```text
新增录音/微信/机构资料
        ↓
自动转写、OCR、去重、脱敏
        ↓
分析优秀动作与失败节点
        ↓
生成能力候选与机构知识候选
        ↓
主管审核、固定测试、影子运行
        ↓
发布新的团队 Skill
        ↓
团队使用并反馈
        ↺
```

IMA 资料源支持先建立清单、按价值排序、受限读取、配额感知、断点续传和受控缓存；IMA 限额不会阻塞本地资料处理。

## 工作空间结构

首次初始化后，会创建一个简单的咨询转化工作区：

```text
咨询转化工作区/
├── 01_机构介绍/
├── 02_科室项目与服务/
├── 03_咨询流程与标准/
├── 04_优秀咨询案例/
├── 05_普通失败与未预约案例/
├── 06_团队培训与反馈/
├── 07_我的产出/
├── 08_团队管理/
│   ├── 01_成员/
│   ├── 02_团队会议/
│   ├── 03_团队数据/
│   └── 04_团队报告/
└── _系统/
    ├── 当前能力包/
    ├── 当前机构知识/
    ├── 患者洞察/
    ├── IMA同步/
    ├── 个人成长/
    └── 发布/
```

用户只需要把资料放到看起来最接近的文件夹，Skill 会自动扫描、识别和整理。

## 隐私与安全边界

- 原始录音、微信聊天、截图和患者资料不进入公开 Skill 包；
- 外部 IMA 知识库不会被写入 Skill 默认内容；
- 患者姓名、电话、微信、病历和头像不会进入团队发布包；
- 未确认的价格、医生、地址、疗效、周期和活动不会被编造；
- 患者洞察只保留群体级决策状态，不生成患者个人画像；
- 不自动发送微信、不自动进行临床诊断、不自动做员工绩效定级；
- 生图能力必须由用户按照所在机构的审核要求使用，不能把虚构素材当作真实患者案例。

